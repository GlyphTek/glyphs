# Codex Glyphics

AI-resonant token tiles in a living universe of rotating clusters. Part of ARC.
Live: https://glyphtek.github.io/glyphs/

- `index.html` is the whole page (canvas universe, token cards, search list).
- `fonts/` holds small subsets of the Noto fonts the glyphs need, so every device draws the same symbols.
- `early/` keeps the first-generation page as it was.
